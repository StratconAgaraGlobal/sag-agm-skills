The mark

The logo stays exactly as it is

No redraw, no cleanup, no "refinement". The artwork below is the file from SAG/Logo/logo SAG.png, unchanged. Everything else in this system is built around it.

What is in the file

A shield carrying a yellow-to-amber gradient, a diagonal band, and a second shield outline nested inside the first. 1681 × 1863 px, transparent background, no wordmark attached.

gradient #F8AF41 → #F5E334
dominant value #F9C939

One thing to know before using it

The diagonal band and the ring between the two shield outlines are transparent, not white. On paper that reads correctly, because the paper is white. On a yellow cover or a graphite slide, those areas fill with the background and the shield collapses into a solid blob.

So the same artwork is supplied in two builds. Nothing is redrawn — the second build simply has those interior areas filled white.

"PT" stays off the mark

Hierarchy comes from weight

With one family, a jump of two weights does the work a change of typeface used to do. Titles at 800, section heads at 700, body at 400, and long introductory paragraphs at 300 so they read as a different voice without a second font.

Numbers line up

Turn on tabular figures for every table, tracker and fee schedule — font-feature-settings: "tnum" on the web, and the Number Forms setting in Word. Permit dates and rupiah columns must align on the decimal.

Licence

SIL Open Font License. Install it on every workstation, embed it in a PDF sent to a ministry, and put it on the website, with no licence conversation and no per-seat cost.

When the font is not installed

A client or ministry opening a .docx without Plus Jakarta Sans will get a substitution, so choose it yourself in the theme: Aptos on current Office, Calibri on older versions, and "Plus Jakarta Sans", "Segoe UI", system-ui, sans-serif as the web stack. Send anything final as PDF with fonts embedded and the question disappears. If the firm ever wants a more neutral alternative, Archivo is the closest substitute with the same weight range — but it is a replacement for the whole system, never a second family alongside it.

05
Signature graphic

The Complexity Line

Taken from the deck artwork already in use and turned on its side, so it runs the way an argument runs. Tangled strands enter from the left, converge to a single point, pass through the sentence, and leave as one yellow line.

Where the colour changes

The strands carry no brand colour at all — cold grey, unresolved. Yellow appears only at the convergence and never before it. The point of the graphic is that the yellow is earned.

Seeded, not random

Every instance is generated from a fixed number, so a cover reprinted next year is identical to the first run. Lock three seeds now — one with the sentence, one without, one short crop for email and web — and never regenerate them.

Using it

Covers, title slides, section dividers, the website header, email footers. On graphite or slate only. Never on yellow, never behind body copy, and never mirrored — it reads left to right because that is the direction of the argument.

Method

Five moves, in this order

Map the whole path. Every licence the activity requires, by KBLI, investment status, sector and location.
Sequence to the critical path. Exact filing order, with everything that can run in parallel running in parallel.
Stress-test the weak points. Where the timeline is most likely to fail, and the mitigation designed first.
Cost it defensibly. A realistic timeline and full cost picture under normal and contingency scenarios.
Track the rules as they move. Continuous monitoring — this is how the Bintan Pemda-to-KEK authority shift was caught.

Production checklist

  • Two logo files, named so nobody guesses. SAG-logo-on-white.png (interior transparent) and SAG-logo-on-colour.png (interior filled white). Export each at 2000 px tall on a transparent ground, plus the original vector if it still exists — if it does not, have the shield traced once from the 1681 px master and keep that as the archive copy.
  • Favicon. .ico at 16/32/48 px — the shield on a solid #F9C939 tile, not the shield alone, because the outline ring closes up at that size.
  • Font. Install Plus Jakarta Sans on every workstation. OFL, so office-wide install and PDF embedding are permitted.
  • Office theme. SAG.thmx with the colours above and Plus Jakarta Sans in both the heading and body slots.
  • Word templates. SAG_Letter.dotx and SAG_Report.dotx with named styles — SAG Cover, SAG H1, SAG H2, SAG Lede, SAG Body, SAG Table, SAG Ref — so nobody formats by hand.
  • PowerPoint template. SAG_Deck.potx with the six masters built as slide layouts, not as slides.
  • The Complexity Line. Export three fixed seeds as SVG and 4000 px PNG. Fix them now and never regenerate.
  • Stamp. Send the single-colour SVG to the stamp maker at 38 mm and ask for a proof impression before the batch.
  • Retire the old file. Delete the gradient PNG from shared drives on the day the new artwork lands, or it will keep reappearing in decks for years.

Where this came from

Positioning, tagline, method, sectors, case references and figures were drawn from the SAG knowledge graph at graphify-out/ — the company profile, SAG BOOK, and the mission, services, risk-reduction and case-study sections. The yellow was measured pixel by pixel from SAG/Logo/logo SAG.png: the gradient runs #F8AF41 at the lower-left tip to #F5E334 at the upper-right shoulder, with #F9C939 dominant across the mark. That dominant value is the brand colour, unchanged.

What is not decided here

Photography direction, the website, and the email signature block all follow from this system but are not specified in it. All dates, reference codes, contact details and permit statuses in the mockups are specimen content for layout only.
